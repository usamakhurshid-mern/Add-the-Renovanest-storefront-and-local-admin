# Renovanest

Curated storefront for an Instagram account. People browse here and buy on AliExpress.

```bash
npm install
npm run dev
```

Open the site at http://127.0.0.1:5173/ and the editor at http://127.0.0.1:5173/admin.

The starter admin password is `mirra`. Change it inside Brand. It only locks the form on this computer.

Saving writes `public/content.json`. That file is what the shop renders. `npm run dev` has to be running for Save to work.
